> **Tools:** `SolidWorks` `Geomagic` `CarSim` `Vehicle Dynamics`

> Catalog-based component sizing, Euler column buckling verification ($S.F. = 2.11$), and modular Bosch Rexroth NG6 sandwich manifold CAD packaging for a 150-bar system.  
> **Tools:** `SolidWorks` `Fluid Power` `Bosch Rexroth Standards`

> **Tools:** `SolidWorks` `Tooling Design` `DFM`
